# CapstoneV2

읽기 쉬운 코드와 원본 오픈소스 보존을 우선하는 Capstone 재구성 작업 폴더입니다.

상태(2026-10-10): **V2 시뮬레이션·수집·전처리 기반은 승인된 기본 통합 검증을 통과했습니다(`passed_scoped`, 종료0).** Python 62개·native 30개, 정상/모터1 고장/후기 배터리 비행, resume 복귀와 수집·live/offline 대조를 확인했습니다. 후속 headless 모터·배터리 실행도 정상 종료했습니다. Gazebo GUI 종료 실패는 별도 한계로 보존합니다. AI 모델 2종 학습·비교와 완성 UI는 후속 개발입니다.

기업 BIN은 **실제 관측 항목·단위·기록 주기를 참고하는 자료**이며 학습·검증·최종 시험 데이터로 지정하지 않았습니다. 과거 BIN 재생에서 유효 분석 창이 0개였다는 사실은 보존하지만 현재 V2 완료의 차단 조건은 아닙니다. 증거와 한계는 `검증결과.md`, 후속 순서는 `진행상황_및_인수인계.md`를 따릅니다.

## 핵심 동작

- `motor_fault`는 시뮬레이션 시작부터 상시 중계합니다. 정상은 그대로 통과, 고장 구간에는 한 모터 명령에만 배율을 적용하고 해제하면 그대로 통과합니다.
- 원본 PX4·Gazebo 모터를 수정하지 않고 V2 실험 모델의 입력 경로만 분리했습니다. 출력 숫자 위조가 아니라 stock 모터의 물리 입력에 영향을 주는 설계입니다.
- 배터리는 실행 전에 프로파일/SOC를 선택합니다. 원래 요구 명령으로 V/A/SOC를 근사하며 정밀 전기·추력 결합이나 실측 RPM 모델이 아닙니다.
- MAVLink 수집은 수신 전용입니다. 관측과 정답을 분리하고, 저장 JSONL/기업 BIN을 같은 인과 전처리기에 공급합니다.
- AI 학습·완성 UI·실기체 연결/배포는 이번 범위에 없습니다.

## 폴더 경계

| 폴더 | 내용 |
|---|---|
| `capstone/`, `native/`, `main.py` | V2 제품 코드 |
| `config/`, `models/`, `profiles/` | 공유 설정·승인된 실험 모델·출처 있는 파라미터 |
| `docs/`, `tests/`, `tools/` | 설명·검증·빌드 도구 |
| `external/` | 수정하지 않는 원본 의존성 |
| `.venv/` | V2의 Python 설치 환경 |
| `hermes/` | 빌드·생성 dialect·실험·검증 산출물. Hermes 프로그램 의존성이 아님 |

공유 저장소는 `capstone1-irion/simulation`, 기준 브랜치는 `main`입니다. 저장소 루트가 V2 프로젝트 루트입니다. V1 코드·빌드·가상환경을 실행 의존성으로 사용하지 않습니다. 로컬 V1은 보존하고 Git 과거 이력도 유지하며, main의 현재 파일만 V2로 교체합니다. `external/`, `.venv/`, `hermes/`, 기업 원자료 `log/`는 배포에서 제외합니다. 새 PC는 설치 안내에 따라 의존성을 준비해야 하며 개발 PC의 원시 검증 로그는 clone에 포함되지 않습니다.
